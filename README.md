# VeriStudy IA

> *"Busca en fuentes reales, repasa con IA y comprueba cuánto sabes de verdad."*

## Acerca del proyecto
**VeriStudy IA** es un prototipo de aplicación web educativa diseñado como proyecto escolar para demostrar cómo aprovechar Internet y la inteligencia artificial de forma responsable en el estudio.

## Funciones principales
* **Buscador con fuentes verificadas:** Consulta información académica y muestra el respaldo de cada fuente para evitar la desinformación.
* **Repaso inteligente:** Resume conceptos clave en tarjetas interactivas y ejemplos aplicados a la vida cotidiana.
* **Práctica rápida:** Cuestionario de calentamiento con retroalimentación inmediata.
* **Test de comprensión:** Evaluación con indicador visual (`0%` a `100%`) que mide el nivel de entendimiento del tema y sugiere qué puntos reforzar.

## Nota aclaratoria
Este es un prototipo académico creado con fines educativos. No está afiliado ni respaldado oficialmente por Google.
